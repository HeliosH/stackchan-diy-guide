# m5-pantilt v1.0 元件清单

> LCSC 编号来自官方原理图元件库 + 本仓库补充核实（J3/J8、J6 为 2026-10 经嘉立创元件库逐一验证的原厂 JST 料）；**匹配编号后仍须检查实际型号/封装，是否可机器装配以嘉立创当前服务为准**。
