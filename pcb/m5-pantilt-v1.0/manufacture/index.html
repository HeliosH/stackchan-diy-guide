下单流程

  1. 嘉立创 https://www.jlc.com → PCB 下单 → 上传 m5-pantilt-gerbers-jlcpcb.zip。 参数：2 层、1.6mm、喷锡（HASL）、5 片。
  2. 勾选 SMT 贴片 → 上传 m5-pantilt-bom-jlc.csv + m5-pantilt-cpl-jlc.csv → 元件匹配页逐项确认 LCSC 编号。
  3. 跳线已按串行版处理（无需再改）：串行舵机版（CoreS3 + XL330 / SCS0009）只装 R13、R14（0Ω）；R9–R12 是 PWM 模式的 Core 型号选择跳线，已从 BOM/CPL 中剔除，匹配页不会再出现。
    • 若你要做 PWM/SG90 版：不装 R13/R14（下单时手动设不贴），自行购买 4 颗 0603 0Ω（LCSC C21189）手焊——Core Basic/Gray 短 R9+R11，Core2/CoreS3 短 R10+R12，并在固件显式指定 PWM 类型和引脚；详见 自制配置表。
  4. J1/J2/SW1 为来料件（不在 BOM/CPL 里）：J1 是背面（bottom）2×15 贴片双排排针，到手自己焊（方向照实拍图 ../../../images/m5-pantilt-bottom.png）；J2 排母、SW1 开关同样自备手焊，采购规格见 jlcpcb/BOM.md 第三节。
  5. 通孔件 J3/J8/J5/J6/J7 有 LCSC 料号且支持 THT 插件代工（勾选"通孔插件装配"即可机器焊接，加收插件费；省钱则到手手焊）。

元件速览（详表见 jlcpcb/BOM.md）

  • U1 = MAX3485（窄体 SOIC-8 3.9×4.9mm，半双工收发；PCB 封装已按窄体修正，2026-10 重铺 GND 铜区并通过连通/短路检查）、Q1 = IRLML6402（电源软开关）、Q2 = BC857（方向控制）
  • D1 = SS54、D2 = PMEG3030EP（电源路径）
  • 电容 100µ×4 + 0.1µ×1、电阻 0603 ×15（R13/R14 为 0Ω 跳线）
  • J1/J2 = 2×15 M-BUS 排针/排母（来料）、J3/J8 = JST EH 3pin 舵机口（C160259）、J5 = PH2.0 电池（C2319）、J6 = PH 4pin（C157926）、J7 = XH 5V（C20079）、SW1 = SPDT 开关（来料）

复现命令（kicad-cli 7.0）

cd pcb/m5-pantilt-v1.0
mkdir -p manufacture/jlcpcb/gerbers
kicad-cli pcb export gerbers --output manufacture/jlcpcb/gerbers m5-pantilt.kicad_pcb
kicad-cli pcb export drill --generate-map --excellon-separate-th \
  --output "$(pwd)/manufacture/jlcpcb/gerbers/" m5-pantilt.kicad_pcb
kicad-cli pcb export pos --format csv --units mm --side both \
  --output manufacture/jlcpcb/cpl/pos-both.csv m5-pantilt.kicad_pcb
kicad-cli sch export python-bom --output manufacture/jlcpcb/python-bom.csv m5-pantilt.kicad_sch
# zip 打包 + JLC 格式 BOM/CPL 转换由脚本完成（见本文件生成记录）
