- ERC：58 项 `lib_symbol_issues`——官方原理图符号为多年前库版本，与 KiCad 10 标准库仅 Description/Datasheet 元数据不同，引脚语义一致；重写符号库的风险大于收益，保留。
- ERC：1 项 `footprint_link_issues`——OSHW 丝印 logo 封装仅存在于 PCB，不在原理图中（机械件，无电气意义）。

DRC 与对应检查已无警告。这些警告没有通过修改检查规则或新增排除来隐藏。0错误不代表实板签核；连接器采购型号/高度、机身试装、舵机总线波形及整机功能测试需要实物确认。

PCB/原理图对应检查在 2026-10-15 修复后为 0 警告（此前 39 条为符号元数据差异与机械件封装，未发现电气网络、元件值或电气封装对应错误；机械孔全部保留）。
