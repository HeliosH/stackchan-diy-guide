## 保留的警告

- DRC：32 项旧版/定制封装与 KiCad 10 当前标准库不同。工程中的实际焊盘已嵌入 PCB，制造使用这些几何，不自动用当前库覆盖。当前订单仍需按实际料号抽查焊盘和极性。
- DRC：1 项 SW1 的旧库名 `Button_Switch_THT:SW_CuK_OS102011MA1QN1_SPDT_Angled` 在 KiCad 10 库中找不到；PCB 已嵌入开关封装，其三信号脚和两固定脚尺寸列在 BOM.md 中。
- DRC：8 项 J6/SW1 丝印外形越过板边（侧入接口/侧拨开关的外形），2 项底面丝印重叠。不会改变铜层或安装孔，但板边外轮廓会在制板时截断。
- ERC：29 项旧符号与当前标准库不同，及1项相同 SW1 库名问题。原理图符号使用工程内嵌定义，未进行会改变引脚语义的批量库更新。

这些警告没有通过修改检查规则或新增排除来隐藏。0错误不代表实板签核；连接器采购型号/高度、机身试装、舵机总线波形及整机功能测试需要实物确认。

PCB/原理图对应检查的39条警告为33条 Description/Datasheet 字段差异，以及6个未在原理图出现的机械孔/丝印封装；没有发现电气网络、元件值或电气封装对应错误。报告保留这些信息，不删除机械孔来消除“额外封装”警告。
