## 保留的警告

- ERC：29 项 `lib_symbol_mismatch`——工程内嵌官方符号为多年前的库版本，与 KiCad 10 标准库副本不同（引脚语义一致，含全部 power 符号、SW1、U1、Q2、D1 等）。重写符号库的风险大于收益，保留。检查环境已配置 AppImage 自带的标准符号库表（`~/.config/kicad/10.0/sym-lib-table`），不再有“配置不含符号库”类环境性警告。
- 对应检查：33 项封装 Description/Datasheet 字段与原理图空字段不一致；6 项仅存在于 PCB 的机械件（Hole1–4、LOGO、REF**）。机械孔全部保留，不删除以消除“额外封装”警告。

DRC 已无警告。这些警告没有通过修改检查规则或新增排除来隐藏。0错误不代表实板签核；连接器采购型号/高度、机身试装、舵机总线波形及整机功能测试需要实物确认。

PCB/原理图对应检查 2026-10-15 修复 Q1/Q2 后为 39 条警告（33 条字段元数据差异 + 6 个机械件封装），未发现电气网络、元件值或电气封装对应错误；机械孔全部保留。
